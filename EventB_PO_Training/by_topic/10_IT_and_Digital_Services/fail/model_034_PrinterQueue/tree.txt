model_034  PrinterQueue

1) รหัส guard
   a1   jobCount < 5
   b1   retryPrint < 3

2) Guard tree
   (root)
   └── a1  jobCount < 5
       └── b1  retryPrint < 3

   เส้นทาง:
   a1 -> b1

3) รหัส event
   a1   sendsubmitJob_1
   b1   receivesubmitJob_1
   c1   sendjobQueued_2
   d1   receivejobQueued_2
   e1   sendpagePrinted_3  (guard a1)
   f1   receivepagePrinted_3  (guard a1)
   g1   sendnextPage_4  (guard a1)
   h1   receivenextPage_4  (guard a1)
   i1   sendreprint_5  (guard b1)
   i2   checkloop_pagePrinted_3_loop1  (guard a1)
   j1   receivereprint_5  (guard b1)
   k1   sendreprintDone_6  (guard b1)
   l1   receivereprintDone_6  (guard b1)
   m1   sendjobComplete_7
   m2   checkloop_reprint_5_loop2  (guard b1)
   n1   receivejobComplete_7

4) Event tree แบบย่อ (event ที่ต่อกันเป็นเส้นตรงอยู่ในบรรทัดเดียว)
   (root) INITIALISATION
   └── a1 → b1 → c1 → d1 → e1 → f1 → g1 → h1
       ├── i1 → j1 → k1 → l1
       │   ├── m1 → n1
       │   └── m2 ↺ i1
       └── i2 ↺ e1

   Event tree แบบเต็ม
   (root) INITIALISATION
   └── a1 sendsubmitJob_1
       └── b1 receivesubmitJob_1
           └── c1 sendjobQueued_2
               └── d1 receivejobQueued_2
                   └── e1 sendpagePrinted_3  (guard a1)
                       └── f1 receivepagePrinted_3  (guard a1)
                           └── g1 sendnextPage_4  (guard a1)
                               └── h1 receivenextPage_4  (guard a1)
                                   ├── i1 sendreprint_5  (guard b1)
                                   │   └── j1 receivereprint_5  (guard b1)
                                   │       └── k1 sendreprintDone_6  (guard b1)
                                   │           └── l1 receivereprintDone_6  (guard b1)
                                   │               ├── m1 sendjobComplete_7
                                   │               │   └── n1 receivejobComplete_7
                                   │               └── m2 checkloop_reprint_5_loop2  (guard b1)  ↺ วนกลับไป sendreprint_5
                                   └── i2 checkloop_pagePrinted_3_loop1  (guard a1)  ↺ วนกลับไป sendpagePrinted_3

   เส้นทาง:
   a1 -> b1 -> c1 -> d1 -> e1 -> f1 -> g1 -> h1 -> i1 -> j1 -> k1 -> l1 -> m1 -> n1
   a1 -> b1 -> c1 -> d1 -> e1 -> f1 -> g1 -> h1 -> i1 -> j1 -> k1 -> l1 -> m2 ↺ i1
   a1 -> b1 -> c1 -> d1 -> e1 -> f1 -> g1 -> h1 -> i2 ↺ e1
